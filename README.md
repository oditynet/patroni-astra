# patroni-astra
Версия 2.3:

Все. Протестировал во всех состояниях: автоматизировал неокторые ошибки пользователя при неправильном заполнении settings файла. Работает только онлайн установка. 3ноды собираются в кластер : patroni + etcd + keepalived
1) Правим hosts/hosts 
2) setting.yml правим. 
3) ansible-playbook install.yml -K
вводим пароль так как тут установка идет от пользователя user (локальный юзер). Если надо сменить ,то меняется в anisble.cfg
После запуска производится настрйока нод и ставится на паузу. Копируем репу postgress-pro в /opt/pgpro-cert-*
Нажимаем enter и установка занимает минуты 4-5
Тестируем.



Keepalived следит за мастером etcd и patroni  и все всегда на одной ноде. Мастер переключается быстро,если уронить его. К скрипту добавил сценарий проверки: выключает реплику,добавляет в тестовую базу данные и при включении реплики проверячет все ли данные на всех узлах. Сценарий установки подразумевает иногда ожидания 5,20,30 сек. Надо ждать.
