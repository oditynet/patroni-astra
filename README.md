# patroni-astra

Дописал ansible скрипт по установке на astra 1.7 common/smolensk patroni,etcd,keepalived на 3 ноды. Сейчас протестировал . Все круто. Keepalived следит за мастером etcd и patroni  и все всегда на одной ноде. Мастер переключается быстро,если уронить его. К скрипту добавил сценарий проверки: выключает реплику,добавляет в тестовую базу данные и при включении реплики проверячет все ли данные на всех узлах. Сценарий установки подразумевает иногда ожидания 5,20,30 сек. Надо ждать.
etcd без сертификатов
